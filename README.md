# Travel-Booking-Analytics-Dashboard-SQL-SQLite-Power-BI
Developed an end-to-end analytics workflow using SQLite and Power BI to evaluate booking performance, revenue, cancellation rates and destination trends.
Cleaned and validated booking data, investigated missing values, and used SQL joins and aggregations to compare booking channels and calculate business KPIs.
Built an interactive Power BI dashboard to communicate booking volumes, revenue trends, booking status and channel-level performance.
Identified differences in cancellation rates across booking channels to highlight areas for further business investigation.
