## Project Overview

This project demonstrates an end-to-end data analytics workflow using **SQL, SQLite, and Power BI** to investigate travel booking performance, data quality, revenue, and cancellation behaviour.

The objective was to transform raw booking data into meaningful business insights through SQL-based analysis and dashboard visualisation. The project combines data validation, business KPI calculations, and interactive reporting to demonstrate practical skills relevant to data analyst and business intelligence roles.

## Objectives

- Evaluate booking volumes and cancellation patterns across booking channels.
- Investigate data quality issues, including missing booking amounts and dates.
- Calculate and compare cancellation rates across channels.
- Analyse booking and revenue performance using SQL queries.
- Communicate key findings through a Power BI dashboard.

## Project Workflow

### 1. Data Quality and Validation

Inspected the booking data to identify missing values and assess the consistency of key fields, including booking amounts and dates.

The analysis included investigating incomplete records and validating booking counts to ensure that reported metrics were calculated consistently.

### 2. SQL Analysis Using SQLite

Developed SQL queries to examine booking performance and calculate business metrics.

Key areas of analysis included:

- Booking volumes by channel.
- Cancelled bookings and cancellation rates.
- Revenue and booking amount analysis.
- Data completeness and validation checks.
- Comparisons of performance across booking channels.

### 3. Power BI Dashboard

Developed a Power BI dashboard to present the analysis in a clear, business-focused format.

The dashboard supports the exploration of booking performance, revenue trends, booking status, and channel-level differences.

The aim was to make the results accessible to stakeholders and help identify areas that may require further investigation.

## Key Findings

- **Booking channel performance:** The website channel exhibited the highest cancellation rate in the analysis, at approximately 14.7% in the preliminary results.
- **Cancellation distribution:** Compared booking channels by both cancellation volume and cancellation rate to distinguish the number of cancellations from the proportion of bookings cancelled.
- **Data quality:** Investigated missing booking amounts and dates and checked booking counts to understand how incomplete records could affect the analysis.
- **Business application:** The findings highlight the value of monitoring cancellation behaviour by channel and investigating potential opportunities to improve booking retention.
